## 📌 Problem Statement

Hospitals generate large volumes of patient data including demographics, diseases, assigned doctors, and treatment costs. However, without proper analysis, this data remains underutilized. This project aims to analyze hospital patient data to identify disease patterns, evaluate doctor workload, and understand treatment cost distribution, enabling better decision-making and resource allocation.

---

## 💡 Proposed Solution

This project uses a multi-tool approach to analyze and visualize healthcare data:

* SQL is used for structured querying
* Excel is used for summarization through pivot tables
* Python is used for data analysis and visualization

The system extracts meaningful insights and presents them in a clear and understandable format.

## 🚀 Features
